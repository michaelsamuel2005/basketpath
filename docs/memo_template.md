# One-page memo to a product manager (write this after the real build)

Write it yourself from `reports/findings.md`. It should fit on one page, open with the decision, and
use no number you cannot find in `marts/`.

**To:** Product manager, search and checkout · **From:** (you) · **Date:**

1. **The ask (two sentences).** What you recommend they do next, and the decision it informs.
2. **What the data says (three bullets).** The biggest funnel drop, the search result like for like, the
   mobile checkout gap, each with its interval.
3. **How much to trust it (two bullets).** The audit failures that matter for these numbers, and what engineering
   should fix first.
4. **What it cannot say.** Observational limits, and which question only an experiment can answer.
5. **Proposed test.** Hypothesis, unit, primary metric, guardrails, size and duration (from the findings table).
6. **Proposed OKR (one).** From `docs/okrs.md`, with its baseline.
